## Проекты

### [Интернет-магазин Stellar Burgers](https://github.com/Katerina011/stellar-burgers)

**Стек: `React` · `TypeScript` · `Redux Toolkit` · `React Router` · `REST API` · `Jest` · `Cypress`**

Разработала SPA-приложение «космическая бургерная» с конструктором бургеров, авторизацией пользователей и интеграцией с API заказов.

- Реализовала авторизацию, личный кабинет и защищённые маршруты;
- Настроила глобальное состояние на Redux Toolkit, разработав слайсы (slices) и Thunk-запросы;
- Написала unit-тесты на Jest и E2E-тесты на Cypress;
- Настроила динамическую маршрутизацию для карточек ингредиентов и заказов.


### [Интернет-магазин «Веб-ларёк»](https://github.com/Katerina011/weblarek)

**Стек: `TypeScript` · `ООП`· `MVP` · `Event Emitter` · `REST API`**

Интернет-магазин на чистом TypeScript с архитектурой MVP и Event Emitter.

- Спроектировала разделение приложения на Model, View и Presenter;
- Реализовала типизированные модели каталога, корзины и заказа;
- Добавила валидацию форм и обработку ошибок;
- Создала переиспользуемые UI-компоненты.


### [SkillSwap — платформа обмена навыками](https://github.com/Katerina011/SkillSwap_47_3)

**Командный проект Яндекс Практикума**

**Стек: `React` · `TypeScript` · `CSS Modules` · `clsx` · `LocalStorage` · `Mock API` · `Git`**

SPA-платформа для взаимного обучения и поиска партнеров по обмену знаниями.

- Спроектировала JSON-структуру данных и разработала типизированный API-слой с универсальным загрузчиком моков `loadJson<T>`.
- Реализовала систему MVP-аутентификации через `AuthProvider` и кастомный хук `useAuth` с сохранением сессий в LocalStorage.
- Создала глобальный контекст каталога и оптимизировала поисковую строку с помощью хука `useDebounce` для сокращения лишних рендеров.
- Разработала переиспользуемые UI-элементы (интерактивный `LikeButton` с анимацией и гибкий `Tag` с 7 визуальными режимами).
