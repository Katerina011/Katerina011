## 💼 Проекты

### [Интернет-магазин Stellar Burgers](https://github.com/Katerina011/stellar-burgers)

**Стек: React · TypeScript · Redux Toolkit · React Router · REST API · Jest · Cypress**

Разработала SPA-приложение «космическая бургерная» с конструктором бургеров, авторизацией пользователей и интеграцией с API заказов.

- Настроила маршрутизацию, защищённые и динамические маршруты, страницу 404.
- Реализовала глобальное состояние приложения на Redux Toolkit и асинхронное взаимодействие с API.
- Добавила регистрацию, вход, защиту личного кабинета и редактирование профиля.
- Связала UI-компоненты с данными сервера, реализовала модальные окна и конструктор бургеров.
- Написала Unit-тесты на Jest и E2E-тесты на Cypress для ключевых пользовательских сценариев.
- Использовала TypeScript для строгой типизации приложения.

### [Интернет-магазин «Веб-ларёк»](https://github.com/Katerina011/weblarek)

**Стек: TypeScript · ООП · MVP · Event Emitter · REST API**

Разработала масштабируемый интернет-магазин на чистом TypeScript с классовой архитектурой, паттерном MVP и интеграцией с REST API.

- Разработала полную техническую документацию проекта;
- Спроектировала архитектуру приложения с разделением ответственности между слоями Model, View и Presenter.
- Реализовала событийную модель на основе Event Emitter для взаимодействия компонентов без жёсткой связанности.
- Разработала типизированные модели каталога товаров, корзины и данных покупателя.
- Создала переиспользуемые UI-компоненты: карточки товаров, модальные окна, формы и компоненты корзины.
- Добавила валидацию форм, обработку пользовательских ошибок и взаимодействие с REST API.
- Использовала принципы ООП, классы, наследование и инкапсуляцию при разработке компонентов.
- Настроила строгую типизацию и модульную структуру проекта, обеспечивающую его масштабируемость и поддержку.

### [SkillSwap — платформа обмена навыками](https://github.com/Katerina011/SkillSwap_47_3)

**Командный проект Яндекс Практикума**

**Стек: React · TypeScript · CSS Modules · JSON-моки · localStorage · Git**

Разрабатывала в команде SPA-платформу обмена навыками с каталогом пользователей, поиском, фильтрацией по категориям и авторизацией на основе мок-данных.

- Подготовила JSON-моки пользователей и навыков, добавила изображения и аватарки.
- Реализовала типизированную загрузку данных через универсальную функцию `loadJson<T>` и API-слой для работы с каталогом, категориями, городами и избранными пользователями.
- Добавила mock-аутентификацию с использованием `AuthProvider`, хука `useAuth` и хранения сессии в `localStorage`.
- Создала общий контекст поиска и хук `useCatalogItems` для работы с данными каталога.
- Разработала компоненты `LikeButton` и `Tag`, настроила CSS-модули и CSS-переменные.
- Участвовала в согласовании типов и структуры данных, интеграции функциональности и командной разработке через GitHub.
